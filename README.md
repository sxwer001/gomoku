# 五子棋 · Gomoku

界面简洁的五子棋小游戏：**本地双人**同屏对战，或与 **AI** 对战（三档难度）。
三种形态，**全部离线可用**，免注册、免联网。

## 下载 / 试玩

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| 网页 | [`五子棋.html`](./五子棋.html)（本仓库根目录） | 单个 HTML，双击即玩，无需联网 |
| Windows | [Releases][rel] → `Gomoku-Desktop-1.0.1-portable.exe` | 免安装，双击即用 |
| Windows | [Releases][rel] → `Gomoku-Desktop-1.0.1-setup.exe` | 安装版（含开始菜单 / 桌面快捷方式） |
| 安卓 | [Releases][rel] → `Gomoku-Android-1.0.1.apk` | 传到手机安装，最低 Android 5.0（API 21） |

[rel]: https://github.com/sxwer001/gomoku/releases

> 安卓安装时系统会提示「未知来源应用」，允许即可（APK 使用调试签名）。
> Windows 版未做代码签名，SmartScreen 可能提示「未知发布者」，点「更多信息 → 仍要运行」即可。

## 功能

| 功能 | 说明 |
| --- | --- |
| 对战模式 | 人机对战 / 本地双人（同屏轮流落子） |
| AI 难度 | 简单 / 普通 / 困难 |
| 我方执子 | 执黑先行、执白后行（电脑会自动开局） |
| 棋盘风格 | 简洁（默认）/ 木纹 |
| 辅助操作 | 悔棋、提示（用最强档 AI 给出建议点）、重新开始 |
| 记录 | 实时棋谱列表、比分统计、最后一手标记、胜利连线 |
| 显示 | 坐标开关、手数序号开关、落子音效开关 |
| 其他 | 鼠标悬停虚影、落子动画、快捷键、移动端触屏适配 |

快捷键：`Ctrl/⌘ + Z` 悔棋 · `R` 重开 · `H` 提示 · `Esc` 关闭弹窗

设置与比分保存在浏览器 `localStorage`，下次打开自动恢复。

## AI

AI 使用开源引擎 **[`@algorithm.ts/gomoku`](https://github.com/guanghechen/algorithm.ts)**（MIT 许可），
基于**极小化极大搜索 + Alpha-Beta 剪枝**，并非本项目自行实现。

| 难度 | 特点 | 大致耗时 |
| --- | --- | --- |
| 简单 | 1 层贪心 + 立即胜负判断 | 1~5 ms |
| 普通 | 2~4 层自适应 | 2~60 ms |
| 困难 | 引擎默认，关键局面自动加深（最深 16 层） | 10~200 ms |

三档都具备「能成五必成五」「对手冲四必封堵」的基本战术能力。搜索在 **Web Worker** 中执行，
界面不会卡顿；在不支持 Worker 的场景（例如直接双击打开的 `file://` 页面）自动降级到主线程。

## 实现

- **网页版**：CSS / JS / Worker 全部内联成单个 `五子棋.html`，无任何外部依赖。
- **Windows 版**：Electron 桌面外壳。
- **安卓版**：WebView 外壳，除系统 WebView 外没有其他依赖。
- 游戏源码在 `src/`，三端的构建与测试脚本在 `tools/`。
